## 从判断开始

给一堆物品，要求 AI 判断它们的类别或属性，但是 AI 只能处理数据，所以需要把物品的特征转化为可处理的数据形式。

把物品的特征提取出来，可以从 1～10 之间打个分数。比如苹果的个头大小可以用 5 来表示。

## 加权求和

不同特征对判断的影响不一样，可以给它们不同的权重：

- 大小：权重 3
- 颜色：权重 4
- 形状：权重 3

把特征和权重分别相乘，再加起来，就得到一个分数：

`分数 = 大小 × 3 + 颜色 × 4 + 形状 × 3`

权重不一定代表这个特征有多重要，它们只是参与计算的数字。刚开始可以先随便设一组，训练时模型会调整权重，让结果更接近正确答案。调整后的权重也可能是负数。

如果只判断“是不是苹果”，可以设一个阈值：分数超过阈值就判断为苹果，否则就不是。把阈值从分数里减掉，得到相对分界线的最终分数：

`最终分数 = 大小 × w1 + 颜色 × w2 + 形状 × w3 - 阈值`

这样只要看最终分数是不是大于 0。比如阈值是 50，总分 55 减去 50 得到 5；总分 45 减去 50 得到 -5。

神经网络里常把“减去阈值”写成“加上偏置 b”，也就是 `b = -阈值`。训练时，权重和偏置都会调整。

前面的加权求和再减去阈值，本质上是一个一次函数。把特征画在图上，它用一条直线把苹果和非苹果分开，就像一刀切。特征多的时候，也可以把它理解成高维空间里的一刀切。

不过，只用一条直线不是什么情况都能分开。比如苹果太小或太大都不像苹果，只有中间范围才像，这个边界就需要弯曲，或者组合出多条分界线。神经网络在加权求和后加入激活函数，让多层计算可以组合出这样的边界。激活函数会对每个神经元算出的分数做非线性处理。

比如把苹果的大小记作 `x`，假设大小在 4 到 6 之间才合适。可以先做两个判断：`A = step(x - 4)`，表示 `x` 有没有超过 4；`B = step(x - 6)`，表示 `x` 有没有超过 6。这里的 `step(z)` 在 `z > 0` 时输出 1，否则输出 0。

再算 `A - B`：

- `x = 3`：`A = 0`，`B = 0`，结果是 0
- `x = 5`：`A = 1`，`B = 0`，结果是 1
- `x = 7`：`A = 1`，`B = 1`，结果是 0

这样两个阈值组合起来，只让中间范围的结果变成 1。`step` 是阶跃函数，会按阈值输出 0 或 1，适合说明分界。

## 神经元和层

一个神经元会先做加权求和，再把结果交给激活函数处理。

多个神经元放在一起，就成了一层；一层的输出可以交给下一层继续计算。几层这样连起来，就是一个神经网络。

激活函数会改变分数和输出之间的关系。没有它的话，不管叠多少层加权求和，整体还是一次线性计算，能表示的关系比较有限。常见的激活函数有 ReLU、sigmoid 和 tanh。

## 转成类别分数

苹果的判断也可以不只分“是”和“不是”，而是同时比较苹果、梨、橙子等类别。网络会为每个类别算一个分数，这些还不是概率，通常叫 logits。

这些分数可能是负数，本身也不是概率。Softmax 先对每个分数取指数，把它们变成正数；分数越大，取指数后的数也越大。再把每个数除以所有类别的指数之和，结果就都在 0 到 1 之间，而且加起来等于 1：

`softmax(z_i) = exp(z_i) / 所有类别的 exp(z) 之和`

比如苹果、梨、橙子的结果分别是 `0.7、0.2、0.1`，模型会选分数最高的苹果。这里的数可以当作模型给出的概率分布来看，但不一定等于现实中的准确概率。

如果是“苹果 / 不是苹果”这种二分类，常见做法是用 sigmoid 把一个分数转成 0 到 1 之间的数，再按分界线作判断。
