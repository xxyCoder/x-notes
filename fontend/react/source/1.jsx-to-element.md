# 从 JSX 到 React Element

## 什么是 JSX

> JavaScript XML

一种写在 JavaScript 里的“类 HTML 语法”，最终会被编译成普通 JavaScript

## 先建立整体视角

```text
JSX 源码
  → Babel 在编译时转换成函数调用
  → 函数在运行时创建 React Element 对象
  → 后续才由协调器和渲染器处理
```

## 核心数据设计

React element 是用于描述一部分界面的轻量级不可变对象

```ts
type ReactElement = {
  $$typeof: symbol | number;
  type: unknown;
  key: string | null;
  ref: unknown;
  props: Record<string, unknown>;
};
```

`$$typeof` 用来标识“这是一个 React Element”：采用 `Symbol.for('react.element')`，并为不支持 Symbol 的环境准备数字值。
`type` 描述元素类型；`key`、`ref` 单独存放；普通属性进入 `props`。

处理 `config` 时，不能把所有字段原样塞进 `props`：

1. 提取 `key`，并转成字符串。
2. 提取 `ref`。
3. 只复制 `config` 自身的其他属性，避开原型链属性。
4. 处理子节点：一个子节点直接放入 `props.children`；多个子节点组成数组。


```ts
const supportSymbol = typeof Symbol === 'function' && Symbol.for
const ELEMENT_TYPE = supportSymbol ?  Symbol.for('react.element') : 0xeac7

function makeElement(
  type: unknown,
  config: Record<string, unknown> = {},
  children = config.children
) {
  const props: Record<string, unknown> = {};

  for (const name of Object.keys(config)) {
    if (name !== 'key' && name !== 'ref' && {}.hasOwnProperty.call(config, name)) {
      props[name] = config[name];
    }
  }

  if (children !== undefined) {
    props.children = children;
  }

  return {
    $$typeof: ELEMENT_TYPE,
    type,
    key: config.key == null ? null : String(config.key),
    ref: config.ref ?? null,
    props,
  };
}

function createElement(
  type: unknown,
  config: Record<string, unknown> | null,
  ...children: unknown[]
) {
  const resolvedChildren =
    children.length === 0 ? config?.children :
    children.length === 1 ? children[0] : children;

  return makeElement(type, config ?? {}, resolvedChildren);
}
```

Example:

```tsx
import type { ReactNode } from "react";

function Card({ children }: { children: ReactNode }) {
  return children;
}

const element = (
  <div id="app">
    <Card>
      <span>标题</span>
      {"正文"}
      <strong>重点</strong>
    </Card>
    <footer>页脚</footer>
  </div>
);
```

```js
// element 的值：省略 React 内部字段
{
```
