# Fiber

## 1. 为什么需要 Fiber？

React Element 保存 `type`、`key`、`props` 等输入，但不保存组件状态、更新队列，也没有父子和兄弟指针。

React 用 Fiber 表示一个待处理或已处理的工作单元：读取本次输入，计算子节点，并记录需要提交的操作。

## 2. FiberNode 记录什么？

| 字段 | 存什么 | 具体作用 |
| --- | --- | --- |
| `tag` | 节点的处理类别，如 `FunctionComponent`、`HostRoot`、`HostComponent` | `beginWork`、`completeWork` 根据它进入相应分支 |
| `key` | 同一父节点下用于匹配子节点的 key；没有则为 `null` | 在旧子节点中寻找可复用的 Fiber |
| `elementType` | React Element 原始的 `type` | 协调时判断元素类型是否仍可复用 |
| `type` | 解析后实际用于处理的类型，如 `"div"` 或组件函数 | 创建宿主实例、调用组件等；可能与 `elementType` 不同 |
| `stateNode` | 与 `tag` 对应的实例或内部对象 | 宿主 Fiber 用它取得宿主实例；`HostRoot` 用它取得 `FiberRoot` |
| `return`、`child`、`sibling` | 父 Fiber、首个子 Fiber、下一个兄弟 Fiber | 工作循环据此进入子节点、转向兄弟、回到父节点 |
| `index` | 在同一组兄弟节点中的位置 | 列表协调时与旧位置比较，判断是否移动；无 key 的旧节点也用它查找 |
| `pendingProps` | 本次准备处理的输入；`HostText` 可为文本字符串 | `beginWork` 用它计算本次输出 |
| `memoizedProps` | 上次完成渲染时使用的输入，形状取决于 `tag` | 函数组件、宿主组件保存上次的 props；`HostText` 保存上次的文本内容 |
| `memoizedState` | 上次完成渲染后保留的状态，形状取决于 `tag` | 函数组件保存 Hook 链表入口，`HostRoot` 保存根状态；普通宿主组件和文本通常为 `null` |
| `updateQueue` | 与该类 Fiber 相关的更新或提交数据，形状取决于 `tag` | 根 Fiber、类组件可存状态更新和回调；函数组件可存 Effect 等数据 |
| `dependencies` | 该 Fiber 读取过的 Context 等依赖 | Context 改变时，即使 props 没变，也可判断需要重新处理 |
| `flags` | **当前 Fiber 自己**的操作标记 | 提交时处理插入、更新、ref、Effect 等工作 |
| `subtreeFlags` | **后代**的 `flags` 汇总，不含当前 Fiber 自己的 `flags` | 提交时判断是否进入子树寻找待处理节点 |
| `deletions` | 当前 Fiber 待删除的旧子 Fiber 列表 | 提交时删除它们；`ChildDeletion` 标在当前 Fiber 上 |
| `lanes` | 当前 Fiber 待处理工作的优先级集合 | 判断本次渲染是否需要处理该 Fiber |
| `childLanes` | 后代待处理工作的优先级集合 | 本次优先级与它无交集时，可跳过该子树 |
| `mode` | 并发、严格模式、性能分析等模式的位标记 | 创建子 Fiber 时传递模式，处理时选择相应逻辑 |
| `ref`、`refCleanup` | 要附着的 ref，以及回调 ref 返回的清理函数 | 提交时附着、解除 ref，或调用清理函数 |
| `alternate` | 同一位置的另一个 Fiber 版本，初次创建时可为 `null` | `createWorkInProgress` 复用它构建下一版树 |

`lanes` 和 `childLanes` 是位标记集合，不是一个“优先级数字”。`flags` 和 `subtreeFlags` 分别表示当前节点、后代的提交工作。

### `tag`、`elementType`、`type`

常见的 `tag` 值：

```ts
// tag
export const FunctionComponent = 0
export const HostRoot = 3
export const HostComponent = 5
export const HostText = 6
```

| 例子 | `tag` | `elementType` | `type` |
| --- | --- | --- | --- |
| `<div />` | `HostComponent` | `"div"` | `"div"` |
| `<Button />` | `FunctionComponent` | `Button` 函数 | `Button` 函数 |
| 文本 `"你好"` | `HostText` | 通常为 `null` | 通常为 `null` |
| 根 Fiber | `HostRoot` | `null` | `null` |


### stateNode

| Fiber 的 `tag` | `stateNode` 通常是什么 |
| --- | --- |
| `HostComponent`，如 `<div>` | React DOM 中对应的 DOM 元素 |
| `HostText` | React DOM 中对应的 DOM 文本节点 |
| `FunctionComponent` | `null`；函数组件本身没有实例 |
| `ClassComponent` | 类组件实例 |
| `HostRoot` | `FiberRoot`；其 `containerInfo` 保存挂载容器 |


### `memoizedProps`、`memoizedState` 与 `updateQueue`

| Fiber 的 `tag` | `memoizedProps` | `memoizedState` |
| --- | --- | --- |
| `FunctionComponent` | 上次渲染使用的 props | Hook 链表入口；没有需要记录的 Hook 时可为 `null` |
| `HostRoot` | 通常为 `null` | 根状态，包含当前的 `element` |
| `HostComponent` | 上次渲染使用的标签 props | 通常为 `null` |
| `HostText` | 上次渲染使用的文本内容 | 通常为 `null` |

函数组件 Fiber 的 `memoizedState` 指向第一个 Hook；每个 Hook 自身也有同名的 `memoizedState` 和 `queue`。例如 `useState` 的待处理更新在对应 Hook 的 `queue` 上。函数组件 Fiber 的 `updateQueue` 还可以保存 Effect 链表。

### `flags`、`subtreeFlags`、`deletions`

| 标记 | 具体含义 |
| --- | --- |
| `NoFlags` | 当前 Fiber 没有操作标记；不代表后代没有工作 |
| `Placement` | 新节点插入，或已有节点移动 |
| `Update` | 当前 Fiber 有提交阶段要执行的更新；具体操作取决于 `tag`，不专指修改 DOM 属性 |
| `ChildDeletion` | 当前 Fiber 的旧子节点要删除；待删除节点保存在当前 Fiber 的 `deletions` 中 |

`completeWork` 会把子 Fiber 的 `flags`、`subtreeFlags` 汇总到父 Fiber 的 `subtreeFlags`。所以父 Fiber 的 `flags` 即使是 `NoFlags`，提交阶段仍可能进入它的子树。

## 3. 为什么同时需要 FiberRoot 和根 Fiber？

```text
真实 DOM 容器
    ↑ containerInfo
FiberRoot ←── _internalRoot ── ReactDOMRoot
    current ↓       ↑ stateNode
HostRoot Fiber
    child ↓         ↑ return
组件 Fiber
```

- `ReactDOMRoot` 是 `createRoot` 返回的操作对象，`_internalRoot` 指向内部的 `FiberRoot`。
- `FiberRoot` 保存宿主容器、当前生效的根 Fiber（`current`）、整棵树尚未完成的优先级等信息；它本身不作为工作单元进入 Fiber 工作循环。
- `HostRoot` Fiber 是 Fiber 树的顶点。`root.render(element)` 产生的更新从这里进入，React 处理它的更新队列并协调下面的子树；它本身不生成 DOM 元素。

## 4. 核心流程

```text
createRoot(container)
  → createContainer
    → createFiberRoot
      → 创建 FiberRootNode
      → 创建 HostRoot Fiber
      → 双向关联，初始化根状态和更新队列
  → 标记 DOM 容器
  → 注册事件监听（在 container 上集中监听）
  → 返回 ReactDOMRoot

root.render(React Element)
  → Element 进入 HostRoot 的更新队列
  → 工作循环从 HostRoot 开始调用 beginWork
      → updateHostRoot：处理根更新队列，得到 nextChildren
      → reconcileChildren → mountChildFibers / reconcileChildFibers
  → 在子节点协调中，对每个直接子内容按其类型处理：

    React Element（type、key、props）
      → 根据 key 和 type 查找能否匹配旧 Fiber
      → 能匹配：createWorkInProgress(旧 Fiber, element.props)
      → 不能匹配：createFiberFromElement(element)
          → type 是函数：FunctionComponent
          → type 是普通标签名：HostComponent
          → 写入 type、key、pendingProps

    文本（字符串或数字；它不是 React Element）
      → 查找能否匹配旧 HostText Fiber
      → 能匹配：createWorkInProgress(旧 Fiber, 新文本)
      → 不能匹配：createFiberFromText(新文本)
          → HostText

  → 将得到的 Fiber 接到父 Fiber 的 child／sibling 链上
  → 工作循环继续对子 Fiber 调用 beginWork
  → 处理 FunctionComponent 时调用组件，继续协调其返回值
  → 处理 HostComponent 时读取 props.children，继续协调子内容
```

```ts
// 根 Fiber 在创建 React root 时产生
function createHostRootFiber(mode) {
  return createFiber(HostRoot, null, null, mode);
}

function createFiberFromElement(element, mode, lanes) {
  const { type, key, props } = element;

  const tag =
    typeof type === "function" ? FunctionComponent :
    typeof type === "string"   ? HostComponent :
    null;

  const fiber = createFiber(tag, props, key, mode);
  fiber.elementType = type;
  fiber.type = type;
  fiber.lanes = lanes;
  return fiber;
}

// 字符串作为独立文本子内容被协调时走这里
function createFiberFromText(text, mode, lanes) {
  const fiber = createFiber(HostText, String(text), null, mode);
  fiber.lanes = lanes;
  return fiber;
}

function createWorkInProgress(current: Fiber, pendingProps: unknown): Fiber {
  let wip = current.alternate;

  if (wip === null) {
    // current 已存在，但还没有与它配对的工作 Fiber
    // 首次需要工作副本：创建 alternate
    wip = createFiber(
      current.tag,
      pendingProps,
      current.key,
      current.mode
    );

    wip.elementType = current.elementType;
    wip.type = current.type;
    wip.stateNode = current.stateNode;

    wip.alternate = current;
    current.alternate = wip;
  } else {
    // 已有 alternate：复用工作副本
    wip.pendingProps = pendingProps;
    wip.type = current.type;
  }

  // 保留静态标记，清除上一次渲染产生的操作标记
  wip.flags = current.flags & StaticMask;
  wip.subtreeFlags = NoFlags;
  wip.deletions = null;

  // 以当前 Fiber 的数据作为本次渲染的起点
  wip.lanes = current.lanes;
  wip.childLanes = current.childLanes;
  wip.child = current.child;
  wip.memoizedProps = current.memoizedProps;
  wip.memoizedState = current.memoizedState;
  wip.updateQueue = current.updateQueue;
  wip.dependencies = current.dependencies
    ? { ...current.dependencies }
    : null;
  wip.sibling = current.sibling;
  wip.index = current.index;
  wip.ref = current.ref;

  return wip;
}
```
