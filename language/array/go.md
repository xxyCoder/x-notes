## 1. 底层本质、内存视角

### 数组是固定长度、同类型、连续内存的值类型

~~~go
var a [4]int
~~~

可以把它理解成：

~~~text
a:
[int][int][int][int]
~~~

Go 数组的长度是类型的一部分：

~~~text
[4]int
[5]int
~~~

这是两种不同的类型。数组变量本身直接保存元素，而不是保存一个“数组对象的引用”。

数组赋值会复制全部元素：

~~~go
a := [3]int{1, 2, 3}
b := a

b[0] = 99

fmt.Println(a) // [1 2 3]
fmt.Println(b) // [99 2 3]
~~~

a 和 b 是两份独立的数组数据。

数组元素在内存中按顺序排列。对于 [3]int，可以近似理解为：

~~~text
连续内存：
[int][int][int]
~~~

具体布局还会受到元素类型、对齐和编译器实现影响，但“固定长度、同类型、连续存放”是 Go 数组最重要的特征。

### 数组本身没有动态扩容

数组创建后长度不能改变：

~~~go
a := [3]int{1, 2, 3}
// a = append(a, 4) // 数组不能直接 append
~~~

如果需要动态增加元素，通常使用切片。

### 切片是数组上的一个视图

~~~go
s := []int{1, 2, 3}
~~~

切片不是完整的数组，而是一个描述底层数组范围的小结构。可以把它理解为：

~~~text
指针 ptr -> 底层数组
长度 len
容量 cap
~~~

例如：

~~~go
a := [5]int{10, 20, 30, 40, 50}
s := a[1:4]
~~~

关系大致是：

~~~text
底层数组 a:
[10][20][30][40][50]
     └───────┘
       s
~~~

此时：

~~~text
len(s) == 3
cap(s) == 4
~~~

len 表示从切片起点开始能够访问的元素数量，cap 表示从切片起点开始到底层数组末尾的容量。

切片和底层数组共享数据：

~~~go
a := [3]int{1, 2, 3}
s := a[:]

s[0] = 99

fmt.Println(a) // [99 2 3]
~~~

切片复制时，复制的是切片描述符，不是底层数组：

~~~go
s1 := []int{1, 2, 3}
s2 := s1

s2[0] = 99

fmt.Println(s1) // [99 2 3]
~~~

### 切片扩容可能更换底层数组

~~~go
s := []int{1, 2, 3}
s = append(s, 4)
~~~

append 会返回一个切片。容量足够时，它可能继续使用原来的底层数组；容量不足时，Go 会申请新的底层数组，复制旧元素，再返回指向新数组的切片。

因此要重新接收返回值：

~~~go
s = append(s, 4)
~~~

可以用 len 和 cap 观察切片的逻辑长度和底层容量：

~~~go
fmt.Println(len(s))
fmt.Println(cap(s))
~~~

扩容后，原来和它共享底层数组的其他切片，可能仍然指向旧数组。

## 2. 基础用法、可调用方法

### 创建数组

~~~go
a := [3]int{10, 20, 30}
~~~

让编译器根据元素数量推断长度：

~~~go
a := [...]int{10, 20, 30}
~~~

指定下标初始化：

~~~go
a := [5]int{
    1: 20,
    3: 40,
}
~~~

结果是：

~~~text
[0 20 0 40 0]
~~~

### 访问和修改

~~~go
a := [3]int{10, 20, 30}

fmt.Println(a[0]) // 10

a[1] = 99
fmt.Println(a) // [10 99 30]
~~~

下标越界会触发运行时错误：

~~~go
// a[3] // index out of range
~~~

### 遍历

使用普通 for：

~~~go
for i := 0; i < len(a); i++ {
    fmt.Println(i, a[i])
}
~~~

使用 range：

~~~go
for i, value := range a {
    fmt.Println(i, value)
}
~~~

只需要值时，可以忽略下标：

~~~go
for _, value := range a {
    fmt.Println(value)
}
~~~

### 常见内置操作

数组和切片都可以使用：

~~~go
len(a) // 元素数量
~~~

切片还可以使用：

~~~go
cap(s) // 容量
~~~

添加元素：

~~~go
s = append(s, 4)
s = append(s, 5, 6)
~~~

复制元素：

~~~go
n := copy(dst, src)
~~~

copy 返回实际复制的元素数量，取两个切片长度中的较小值。

截取切片：

~~~go
s[1:3]
~~~

表示下标 1 到 3 之前的元素，也就是下标 1、2。

也可以同时指定容量：

~~~go
s[1:3:3]
~~~

这样得到的切片长度是 2，容量也是 2，后续 append 更容易触发新的底层数组。

### 排序和查找

数组不能直接调用排序方法，但可以传给标准库函数：

~~~go
sort.Ints(s)
~~~

较新的 Go 版本可以使用 slices 包：

~~~go
slices.Sort(s)
slices.Contains(s, 2)
~~~

Go 的数组和切片没有像 Python 或 JavaScript 那样的一组内置实例方法。常见操作主要通过内置函数、标准库函数和 slices 包完成。
