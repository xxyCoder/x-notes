Python 中日常所说的“数组”，通常指 list。

## 1. 底层本质、内存视角

### list 是可动态扩容的引用数组

~~~python
a = [1, 2, 3]
~~~

Python 列表可以近似理解为一块保存对象引用的连续区域：

~~~text
list 内部：
指针 -> int 对象 1
指针 -> int 对象 2
指针 -> int 对象 3
~~~

列表保存的主要是对象引用，而不是把所有对象的完整内容直接塞在列表内存里。

因此，列表可以同时保存不同类型：

~~~python
a = [1, "hello", 3.14, True]
~~~

可以理解为：

~~~text
指针 -> 整数对象
指针 -> 字符串对象
指针 -> 浮点数对象
指针 -> True 对象
~~~

列表本身只需要保存这些对象的位置引用。

### 列表长度和容量是两个概念

列表有当前长度，也会为了后续添加元素而预留一部分空间。

~~~python
a = [1, 2, 3]
a.append(4)
~~~

如果预留空间足够，追加元素可以直接写入空余位置；空间不足时，Python 会申请更大的区域，复制原有引用，再继续使用新的区域。

因此，append 平均来看很快，但扩容那一次需要搬移元素。

### 变量赋值不会复制列表

~~~python
a = [1, 2, 3]
b = a

b[0] = 99

print(a)  # [99, 2, 3]
~~~

a 和 b 指向同一个列表对象。

如果需要创建一个新的列表，可以使用：

~~~python
b = a.copy()
~~~

或：

~~~python
b = a[:]
~~~

这两种方式都是浅拷贝。列表本身被复制了，但列表里的对象仍然可能被多个列表共享：

~~~python
a = [[1, 2], [3, 4]]
b = a.copy()

b[0][0] = 99

print(a)  # [[99, 2], [3, 4]]
~~~

因为外层列表是新的，内层列表仍然是同一个对象。

### 列表和数组对象的区别

Python 的 list 适合存放通用对象。它不要求所有元素类型相同，也不要求元素占用相同大小。

如果需要固定类型、紧凑的数值存储，可以考虑：

- array.array
- NumPy 的 ndarray
- 其他专门的数值数组类型

普通 list 的重点是灵活，而不是像 C 数组那样直接连续存放同类型数值。

## 2. 基础用法、可调用方法

### 创建列表

~~~python
a = [10, 20, 30]
~~~

空列表：

~~~python
a = []
~~~

使用 list：

~~~python
a = list((10, 20, 30))
~~~

使用范围生成：

~~~python
a = list(range(5))
# [0, 1, 2, 3, 4]
~~~

列表推导式：

~~~python
squares = [x * x for x in range(5)]
~~~

结果是：

~~~text
[0, 1, 4, 9, 16]
~~~

### 访问元素

~~~python
a = [10, 20, 30]

a[0]   # 10
a[-1]  # 30
~~~

负数下标从列表末尾开始：

~~~text
a[-1]：最后一个元素
a[-2]：倒数第二个元素
~~~

下标超出范围会抛出 IndexError：

~~~python
# a[3]
~~~

### 切片

~~~python
a = [10, 20, 30, 40, 50]

a[1:4]  # [20, 30, 40]
a[:3]   # [10, 20, 30]
a[2:]   # [30, 40, 50]
a[::2]  # [10, 30, 50]
a[::-1] # [50, 40, 30, 20, 10]
~~~

切片会创建一个新的列表。

### 添加元素

~~~python
a.append(40)
~~~

在末尾添加一个元素：

~~~text
[10, 20, 30] -> [10, 20, 30, 40]
~~~

一次添加多个元素：

~~~python
a.extend([50, 60])
~~~

在指定位置插入：

~~~python
a.insert(1, 99)
~~~

insert(1, 99) 会把原来下标为 1 及之后的元素向后移动。

### 删除元素

按值删除第一个匹配项：

~~~python
a.remove(20)
~~~

按下标删除并返回元素：

~~~python
value = a.pop()
value = a.pop(0)
~~~

pop() 默认删除最后一个元素。

删除整个列表内容：

~~~python
a.clear()
~~~

使用 del 删除下标或切片：

~~~python
del a[0]
del a[1:3]
~~~

### 查询元素

~~~python
a.index(30)  # 返回第一个 30 的下标
a.count(30)  # 统计 30 出现的次数
~~~

判断是否包含：

~~~python
30 in a
~~~

获取长度：

~~~python
len(a)
~~~

### 排序和反转

原地排序：

~~~python
a.sort()
~~~

倒序排序：

~~~python
a.sort(reverse=True)
~~~

返回新的排序列表：

~~~python
b = sorted(a)
~~~

原地反转：

~~~python
a.reverse()
~~~

返回反向迭代器：

~~~python
reversed(a)
~~~

sort() 和 reverse() 会修改原列表；sorted() 不修改原列表，而是返回新列表。

### 遍历

只遍历值：

~~~python
for value in a:
    print(value)
~~~

同时获取下标和值：

~~~python
for index, value in enumerate(a):
    print(index, value)
~~~

同时遍历多个列表：

~~~python
for x, y in zip(a, b):
    print(x, y)
~~~
